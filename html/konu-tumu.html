1.3Kontrol yapıları

  • if–else: Koşul sağlanırsa bir dal, sağlanmazsa diğer dal; ikisi aşağıda birleşip devam eder. else yoksa “Hayır” dalı doğrudan birleşme noktasına gider.
  • İç içe if / switch–case: Her koşul ayrı karar kutusu; switch'te sırayla kontrol edilir, sonunda default olmalıdır (menü örneği: tanımsız tuşa basılırsa uyarı).
  • while: Önce koşula bakılır; koşul doğruysa döngüye girilir, yanlışsa döngü atlanır (sıfır kez çalışabilir).
  • do–while: Gövde en az bir kez çalışır, sonra koşula bakılır.
  • for: Başlangıç (bir kez), koşul (her turda), artım (her tur sonunda); akış diyagramında üçü tek altıgen döngü sembolüne yazılır, gövdeden altıgene geri ok döner, “Hayır” çıkışı döngünün sonrasına gider. Örnek: for(i=1; i<n; i++) n=1 ise hiç girmez; n=10 ise 9 kez girer.
  • İç içe döngüler: İç döngü bittikten sonra yapılacak bir işlem (X), dış döngüye dönüş yolunun üzerine çizilir; while bittikten sonra yapılacak işlem (Y) dıştaki for'a dönüş yoluna konur.

2Karmaşıklık Analizi

2.1Tanım ve amaç

Karmaşıklık analizi, bir algoritmanın kodlanmadan önce davranışının teorik olarak ortaya konmasıdır; genelde kaba koddan veya akış diyagramından yapılır. Aynı işi yapan algoritmaları karşılaştırmak (hız veya bellek açısından) için kullanılır. Kodlayıp ölçmek hem zaman alır hem de yanıltıcıdır: farklı makine, RAM, programlama dili ve programcı tecrübesi sonucu etkiler (fizikteki eşit koşullarda deney gibi).

2.2Dört terim

2.3Asimptotik notasyonlar

  • O (“order of”) – en kötü durum, üst sınır: algoritma bundan daha kötü çalışamaz. Genelde hesaplanan budur.
  • Ω – en iyi durum, alt sınır: bundan daha iyi çalışamaz.
  • Θ – ortalama durum. Ders kapsamında: en iyi ve en kötü durum zaman karmaşıklıklarının derecesi aynıysa ortalama durumdan söz edebiliriz (ör. 3n+1 ve 4n ⇒Θ(n)). Dereceler farklıysa (n ve n2) Θ verilmez.

2.5Sayma kuralları

  1. Değişken tanımları/ilk atamalar ihmal edilir ve bu yazılır: “değişken tanımlamaları ihmal edilmiştir”. İhmal edilmezse sadece sabit terim değişir.
  2. for(k=0; k<n; k++): atama 1 kez, kontrol n+1 kez (k=0..n), artırma n kez ⇒2n+2. Gövdeye n kez girilir.
  3. for(k=1; k<n; k++): atama 1, kontrol n, artırma n−1 ⇒2n. Gövdeye n−1 kez girilir.
  4. İç döngü maliyeti, dış döngünün kaç kez çalıştırdığıyla çarpılır. İç döngünün sınırı dış indise bağlıysa (k<i) toplam alınır: ∑i=1n−1​i=2n(n−1)​.
  5. if kontrolü her zaman sayılır; if'in içi en kötü durumda her seferinde, en iyi durumda hiç çalışmayabilir.
  6. Fonksiyon içinden başka fonksiyon çağrılıyorsa onun maliyeti ayrıca eklenir; return 1 işlemdir.

4) Özyinelemeli (recursive) faktöriyel

int fakt(int n) {
   if (n <= 1)            // n kez kontrol
      return 1;           // 1 kez
   else
      return n * fakt(n-1);   // n-1 kez

6) İkili arama neden logn?

  ilk = 0;  son = n - 1
  while (ilk <= son)

     if (D[orta] == x) return orta
     if (x < D[orta]) son = orta - 1

Kumeleme ( int D[], int N)
{
    int H[N];                    // hip agaci, H[0] = kok
    int i, k;

    for (i=0; i<N; i++)          // A) AGAC OLUSTURMA
        HipEkle(H, i, D[i]);     // teker teker ekle

    for (k=N-1; k>=0; k--) {     // B) SIRALAMA
        D[k] = H[0];             // koku kopar, kenara yaz
        KokSil(H, k);            // sondakini koke koy
    }
}

HipEkle ( int H[], int son, int x)
{                                // x'i zigzag'a gore ekle
    int c, ebeveyn, gecici;
    H[son] = x;                  // ilk bos yer
    c = son;
    ebeveyn = (c-1)/2;
    while (c>0 && H[c]>H[ebeveyn]) {
        gecici = H[c];           // yukari tasi
        H[c] = H[ebeveyn];
        H[ebeveyn] = gecici;
        c = ebeveyn;
        ebeveyn = (c-1)/2;
    }
}

KokSil ( int H[], int son)
{                                // agac: H[0..son]
    int c, buyuk, gecici;
    H[0] = H[son];               // en sondaki koke
    son = son-1;
    c = 0;
    while (2*c+1 <= son) {       // cocugu var
        buyuk = 2*c+1;           // sol cocuk
        if (2*c+2 <= son && H[2*c+2] > H[buyuk])
            buyuk = 2*c+2;       // sag daha buyuk
        if (H[c] >= H[buyuk])    // hip saglandi
            break;
        gecici = H[c];           // BUYUK cocukla
        H[c] = H[buyuk];         // yer degistir
        H[buyuk] = gecici;
        c = buyuk;
    }
}

4.1Veri yapısı ve soyut veri tipi

Bir veri yapısı tanımlarken iki şey belirlenir: (1) nesneler kümesi (ne depolanacak: tam sayı, ondalık, karakter, öğrenci kaydı…), (2) işlemler kümesi (bu veriler üzerinde hangi işlemler yapılacak). Node* List::InsertNode(int index, double x) {
    if (index < 0) return NULL;
    int currIndex = 1;
    Node* currNode = head;
    while (currNode && index > currIndex) {    // index'inci dugumu bul
        currNode = currNode->next;
        currIndex++;
    }
    if (index > 0 && currNode == NULL) return NULL;   // oyle bir dugum yok
    Node* newNode = new Node;
    newNode->data = x;
    if (index == 0) {                          // basa ekle
        newNode->next = head;
        head = newNode;
    } else {                                   // currNode'dan sonra ekle
        newNode->next = currNode->next;
        currNode->next = newNode;
    }
    return newNode;
}
Bağlantı sırası

Araya eklemede önce newNode->next = currNode->next, sonra currNode->next = newNode yapılır. Ters sırada yapılırsa listenin geri kalanı kaybolur.

public:
    Queue(int size = 10) { values = new double[size]; maxSize = size;
                           front = 0; rear = -1; counter = 0; }
    bool IsEmpty() { return counter == 0; }
    bool IsFull()  { return counter >= maxSize; }
    bool Enqueue(double x) {
        if (IsFull()) { cout << "Kuyruk dolu"; return false; }
        rear = (rear + 1) % maxSize;            // dairesel ilerleme
        values[rear] = x;  counter++;
        return true;

    bool Dequeue(double& x) {
        if (IsEmpty()) { cout << "Kuyruk bos"; return false; }
        x = values[front];
        front = (front + 1) % maxSize;
        counter--;
        return true;
    }
private:
    int front, rear, counter, maxSize;  double* values;
};

6İkili Ağaçlar ve İkili Arama Ağaçları

6.1Neden ağaç?

Bağlantılı listede arama, ekleme, silme doğrusaldır (O(n)). Hedef: bu işlemleri O(logn)'e indiren bir yapı. Ağaç düğümlerden oluşur: kök (ebeveyni yok), çocuk/ebeveyn, yaprak (çocuğu yok), kardeş (aynı ebeveyn), yol uzunluğu (kenar sayısı), derinlik (kökten düğüme yol), yükseklik (düğümden en uzak yaprağa yol; yapraklar 0, ağacın yüksekliği = kökün yüksekliği). İkili ağaç: her düğümün en fazla iki çocuğu vardır.

6.2İfade ağaçları

Yapraklar sayı/değişken, iç düğümler işlemdir. Burada önemli husus: sayılar kesinlikle yaprakta olacak video 13 00:03. Toplama/çarpmada sol–sağ yer değiştirebilir ama çıkarma ve bölmede sıra önemlidir.

  • Sonek ifadesinden ağaç: soldan sağa okunur; işlenenler beklenir, işlem gelince son iki alt ağaç onun sol ve sağ çocuğu olur (yığın mantığı). Örnek a b c * + d e * f + g * +: bc*→a+(b*c)→de*→(d*e)+f→((d*e)+f)*g→ kök +.
  • Eşitlikten ağaç: parantez ve işlem önceliğine dikkat edilerek en içten dışa doğru alt ağaçlar kurulur.

6.4İkili arama ağacı (İAA)

Kural: her X düğümü için sol alt ağaçtaki tüm anahtarlar X'ten küçük, sağ alt ağaçtakiler büyüktür – bu ikili ağacın her aşamasında, her kademede geçerli olacak. Harflerde alfabetik önde olan soldadır. Eşit değer için bir kural belirlenip (ör. sağa) ona sadık kalınır.

  • Arama: kökten başla; aranan küçükse sola, büyükse sağa; NULL'a gelinirse yok. Dengeli ağaçta O(logn), ip gibi dizilmiş ağaçta O(n).
  • En küçük / en büyük: sürekli en sola / en sağa gidilir (NULL'ı gördüğüm yerdeki bir önceki eleman en küçük).
  • İçkök gezme sıralı listeyi verir – ayrıca sıralama algoritması gerekmez.
  • Ekleme: arama gibi inilir, NULL bulunan yere yaprak olarak eklenir. Sıralı gelen veri (1,2,3,…) ağacı sağa doğru “ip gibi” uzatır.

  • Silme (hocanın kuralları):

    1. Yaprak ⇒ doğrudan silinir.
    2. Tek çocuklu ⇒ çocuğu, silinen düğümün ebeveynine (dedeye) bağlanır.
    3. İki çocuklu ⇒ sağ alt ağacın en küçüğü (minimumu) silinen düğümün yerine geçer video 12 43:31; sonra o eleman eski yerinden (1. veya 2. kurala göre) silinir.

  if (d == NULL) return YeniDugum(x)

9.1B+ ağacı

  • Çocuk sayısı 3 ve daha fazla olan çok yollu dengeli ağaç (M-ary); çocuk sayısı arttıkça yükseklik logM​n'e düşer, disk erişimi azalır.
  • Bütün veriler yapraklardadır, yapraklar aynı seviyededir; iç düğümler sadece yol gösteren anahtarları tutar. Bir iç düğümdeki i. anahtar, i+1. alt ağacın en küçük verisidir (sağdakinin minimumu yukarı anahtar olarak kopyalanır).

  • Hocanın formülleri (M: iç düğüm çocuk sayısı, L: yaprak parametresi; aksi söylenmezse L=M):

    En fazlaEn az
    İç düğüm anahtarM−1⌈M/2⌉−1
    Yaprak veriL−1⌈L/2⌉−1
    KökM−11 (kökün “süperliği”)

    Soru dilinden çeviri: “iç düğüm çocuk sayısı 4” ⇒M=4; “iç düğüm anahtar sayısı 3” ⇒M=4; “yapraklarda tutulan maksimum veri 4” ⇒L=5 (2025 final için WhatsApp'ta da M=4, L=5 sonucuna varılmış).

  • Ekleme: yaprağa sıralı eklenir. Yaprak taşarsa (L veri): sola ⌊L/2⌋ en küçük, sağa kalanlar; sağdakinin en küçüğü yukarı kopyalanır. İç düğüm taşarsa (M anahtar): sola ⌈M/2⌉−1 anahtar, ⌈M/2⌉. anahtar yukarı taşınır, kalanlar sağa. Kök bölünürse yeni kök oluşur.
  • Silme: veri yapraktan silinir. Yaprak minimumun altına düşerse sağ kardeşiyle (en sağdaki yaprak ise sol kardeşiyle) birleştir–böl (veriler iki yaprağa yeniden paylaştırılır); bu da minimumu sağlayamıyorsa iki yaprak birleştirilir ve üstteki anahtar silinir (iç düğüm de aynı mantıkla düzeltilir). Anahtarlar her zaman “sağ alt ağacın en küçüğü” olacak şekilde güncellenir. B şıkkını yanlış yaparsanız C şıkkı da otomatikman yanlış olacak.

Örnek: M=L=4 ile K, L, M, N, O, P, Q, R, S, T ekle; N ve O sil

Parametreler: iç düğüm çocuk sayısı M=4 ⇒ iç düğümde en fazla M−1=3, en az ⌈M/2⌉−1=1 anahtar; L=4 ⇒ yaprakta en fazla L−1=3, en az ⌈L/2⌉−1=1 veri.

9.2Graflar: BFS, DFS ve sonrakök

  • Gösterim: komşuluk matrisi (n2 yer) veya komşuluk listesi (seyrek graflarda tercih edilir).
