3.1Araya sokma sıralama (Insertion sort)

Mantık: Dizi iki parçaya ayrılır: solda sıralı kısım, sağda sırasız kısım. İlk eleman sıralı kabul edilir. Sırasız kısmın ilk elemanı elde tutulur (ekle), sıralı kısımla sondan başa karşılaştırılır; kendisinden büyük olanlar bir sağa kayarak yer açar, boşluğa ekle yerleştirilir (iskambil kağıdı dizme gibi).

void arayaSokma(int D[], int n) {
  int i, k, ekle;                          // ihmal
  for (i = 1; i < n; i++) {                // 1. eleman yerinde kalir
     ekle = D[i];                          // siradaki eleman elde
     for (k = i-1; k >= 0 && ekle <= D[k]; k--)
        D[k+1] = D[k];                     // buyuk eleman bir saga kayar
     D[k+1] = ekle;                        // bosluga yerlestir
  }
}

3.2Seçmeli sıralama (Selection sort)

Mantık: Dizideki en küçük eleman seçilir ve en başa konur; kalanlar içinden en küçük seçilip ikinci sıraya konur…

void secmeli(int D[], int n) {
  int i, j, enk, indis;                    // ihmal
  for (i = 0; i < n-1; i++) {
     enk = D[n-1];  indis = n-1;           // EN SONDAKI eleman en kucuk kabul edilir
     for (j = i; j < n-1; j++)
        if (D[j] < enk) { enk = D[j]; indis = j; }
     D[indis] = D[i];                      // bastaki eleman en kucugun yerine
     D[i] = enk;                           // en kucuk basa
  }
}

3.3Kabarcık sıralama (Bubble sort)

Mantık (deniz dalgası): Her “dalga hareketinde” komşu elemanlar karşılaştırılır, büyük olan sağa geçer. Bir hareket sonunda en büyük eleman en sona yerleşir, küçükler öne yaklaşır (çift yönlü etki). Her harekette iç döngü bir eksik çalışır.

void kabarcik(int D[], int n) {
  int gecici, k, hareket;                  // ihmal
  for (hareket = 0; hareket < n-1; hareket++)          // dalga hareketi
     for (k = 0; k < n-1-hareket; k++)                // komsu karsilastirma
        if (D[k] > D[k+1]) {
           gecici = D[k];  D[k] = D[k+1];  D[k+1] = gecici;
        }
}

3.4Birleşmeli sıralama (Merge sort)

Mantık (böl ve fethet): Dizi pivot = (ilk indis + son indis)/2, aşağı yuvarlanır ile ikiye bölünür (pivot ve solu sol parçada). Tek eleman kalana kadar bölünür. Sonra sıralı parçalar ilk elemanları karşılaştırılarak birleştirilir.

Hip özelliği (ders varsayımı): her düğüm çocuklarına eşit veya onlardan büyüktür (max-heap); tersi de olabilir ama bir kural seçilip sonuna kadar uygulanır.

Kumeleme ( int D[], int N)
{
    int H[N];                    // hip agaci, H[0] = kok
    int i, k;

    for (i=0; i<N; i++)          // A) AGAC OLUSTURMA
        HipEkle(H, i, D[i]);     // teker teker ekle

    for (k=N-1; k>=0; k--) {     // B) SIRALAMA
        D[k] = H[0];             // koku kopar, kenara yaz
        KokSil(H, k);            // sondakini koke koy
    }
}

HipEkle ( int H[], int son, int x)
{                                // x'i zigzag'a gore ekle
    int c, ebeveyn, gecici;
    H[son] = x;                  // ilk bos yer
    c = son;
    ebeveyn = (c-1)/2;
    while (c>0 && H[c]>H[ebeveyn]) {
        gecici = H[c];           // yukari tasi
        H[c] = H[ebeveyn];
        H[ebeveyn] = gecici;
        c = ebeveyn;
        ebeveyn = (c-1)/2;
    }
}

KokSil ( int H[], int son)
{                                // agac: H[0..son]
    int c, buyuk, gecici;
    H[0] = H[son];               // en sondaki koke
    son = son-1;
    c = 0;
    while (2*c+1 <= son) {       // cocugu var
        buyuk = 2*c+1;           // sol cocuk
        if (2*c+2 <= son && H[2*c+2] > H[buyuk])
            buyuk = 2*c+2;       // sag daha buyuk
        if (H[c] >= H[buyuk])    // hip saglandi
            break;
        gecici = H[c];           // BUYUK cocukla
        H[c] = H[buyuk];         // yer degistir
        H[buyuk] = gecici;
        c = buyuk;
    }
}

3.6Hızlı sıralama (Quick sort)

Mantık: Bir pivot seçilir; pivottan küçükler sola, büyükler sağa geçer ve pivot sıralamadaki yerini bulur. Sonra sol ve sağ parçalara aynı işlem uygulanır. Birleşmeliden farkı: birleştirme adımı yok, bölerken sıralıyor.

Hoca derste vurguladı video 7 Sıralama 4 17:08, 35:41

Pivotu belirleme serbestliği hızlı sıralamada bize ait (en sondaki, en baştaki, (ilk+son)/2, ortanca…). Ama bir sayıya odaklanmamak lazım; genel geçer bir kural belirleyip bütün adımlarda uygulamamız lazım. Sınav sorusunda kural verilir: 2020 “en sondaki kelimeyi pivot seçiniz”, 2024 “en baştaki kelimeyi pivot olarak seçiniz”. Eşit elemanlar pivotun yanına (genelde küçükler grubuna) alınır.

Tek dizi üzerinde yer değiştirme (hocanın yöntemi, pivot en sonda): soldan her eleman pivotla karşılaştırılır. Küçükse yerinde kalır. Büyükse 3 adım: (1) eleman pivotun yerine yazılır, (2) pivotun hemen önündeki eleman boşalan yere yazılır, (3) pivot bir sola kayar. Yeni gelen eleman tekrar kontrol edilir. Pivot ortadaysa sağındaki küçükler aynı mantıkla soluna alınır.

HizliSirala(D, ilk, son)
   if (ilk < son)
      p = Bolumle(D, ilk, son)
      HizliSirala(D, ilk, p-1)
      HizliSirala(D, p+1, son)

Bolumle(D, ilk, son)                 // pivot: en sondaki
   pivot = D[son];  p = son;  i = ilk
   while (i < p)
      if (D[i] > pivot)
         D[p] = D[i];  D[i] = D[p-1];  D[p-1] = pivot;  p = p-1
      else  i = i+1
   return p

Mantık: En önemsiz haneden (sayıda birler basamağı, kelimede son harf) başlanır; elemanlar o hanedeki değere göre kovalara (sayılarda 0–9 = 10 kova; Türkçe kelimelerde 29+ harf kadar kova) geliş sırasıyla dağıtılır, kovalar sırayla toplanır. Geçiş sayısı = en uzun elemanın hane sayısı.
