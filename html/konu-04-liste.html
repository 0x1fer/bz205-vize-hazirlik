4Listeler ve Bağlantılı Listeler

4.1Veri yapısı ve soyut veri tipi

Bir veri yapısı tanımlarken iki şey belirlenir: (1) nesneler kümesi (ne depolanacak: tam sayı, ondalık, karakter, öğrenci kaydı…), (2) işlemler kümesi (bu veriler üzerinde hangi işlemler yapılacak). Soyut veri tipi (SVT) = soyut veri yapısı: dildeki temel tipleri kullanarak oluşturduğumuz yeni tip (kum + çimento → beton benzetmesi). C++'ta class ile tanımlanır.

  • class – struct farkı: class içinde değişkenler ve fonksiyonlar tanımlanabilir (fonksiyonu sadece sınıf içindekiler kullanır); struct'ta fonksiyonlar dışarıda tanımlanır ve başka yerlerden erişilebilir (risk).
  • SVT avantajları: modülerlik (kütüphane bir kez yazılır), bilgi gizleme, hızlı prototipleme. Dezavantajı: verimlilik kaybı (kullanılmayan yetenekler de yüklenir).

4.3Liste işlemleri (slayt örneği: 34, 12, 52, 16, 12)

  • printList: listeyi yaz.  makeEmpty: listeyi boşalt (dönem bitti, yeni ders).
  • find(52) → 3 (konumu döner; bulunamazsa 0/NULL). Sıralı olmadığı için baştan tek tek bakılır.
  • insert(3, x) → 34, 12, 52, x, 16, 12 (3. veriden sonra ekle; tren vagonu araya eklemek gibi).
  • remove(52) → 34, 12, 16, 12 (vagonu çıkarıp önceki ve sonrakini bağlamak).
  • findKth(5) → 12 (5. eleman). Ders varsayımı: her veriden bir tane vardır.

4.4Bağlantılı liste gerçekleştirmesi (C++)

class Node {
public:
    double data;      // veri (ogrenci icin no, ad, soyad olabilir)
    Node*  next;      // sonraki dugume isaretci
};
class List {
public:
    List(void) { head = NULL; }             // yapici: bos liste
    ~List(void);                            // yikici
    bool  IsEmpty() { return head == NULL; }
    Node* InsertNode(int index, double x);
    int   FindNode(double x);
    int   DeleteNode(double x);
    void  DisplayList(void);
private:
    Node* head;       // ilk dugumu gosterir; verisi yok (lokomotif)
};

head private'tır: listenin başlangıcını dışarıdan kimse değiştirememeli. Son düğümün next'i NULL'dır.

InsertNode – belirtilen konumdan sonra ekleme

Node* List::InsertNode(int index, double x) {
    if (index < 0) return NULL;
    int currIndex = 1;
    Node* currNode = head;
    while (currNode && index > currIndex) {    // index'inci dugumu bul
        currNode = currNode->next;
        currIndex++;
    }
    if (index > 0 && currNode == NULL) return NULL;   // oyle bir dugum yok
    Node* newNode = new Node;
    newNode->data = x;
    if (index == 0) {                          // basa ekle
        newNode->next = head;
        head = newNode;
    } else {                                   // currNode'dan sonra ekle
        newNode->next = currNode->next;
        currNode->next = newNode;
    }
    return newNode;
}
Bağlantı sırası

Araya eklemede önce newNode->next = currNode->next, sonra currNode->next = newNode yapılır. Ters sırada yapılırsa listenin geri kalanı kaybolur.

Yürütme zamanı: en kötü (sona ekleme) T(n)=3n+8⇒O(n); en iyi (başa ekleme) sabit ⇒Ω(1) (ayrıntı: çözüm dosyası).

FindNode ve DeleteNode

int List::FindNode(double x) {
    Node* currNode = head;
    int currIndex = 1;
    while (currNode && currNode->data != x) {
        currNode = currNode->next;
        currIndex++;
    }
    if (currNode) return currIndex;
    return 0;                                  // bulunamadi
}
int List::DeleteNode(double x) {
    Node* prevNode = NULL;
    Node* currNode = head;
    int currIndex = 1;
    while (currNode && currNode->data != x) {
        prevNode = currNode;
        currNode = currNode->next;
        currIndex++;
    }
    if (currNode) {
        if (prevNode) prevNode->next = currNode->next;   // aradan cikar
        else          head = currNode->next;             // bastaki silindi
        delete currNode;
        return currIndex;
    }
    return 0;
}
void List::DisplayList() {
    int num = 0;
    Node* currNode = head;
    while (currNode != NULL) {
        cout << currNode->data << endl;
        currNode = currNode->next;
        num++;
    }
    cout << "Dugum sayisi: " << num << endl;
}

4.5Liste çeşitleri

  • Dairesel bağlantılı liste: son düğüm NULL yerine ilk düğümü gösterir.
  • Çift yönlü bağlantılı liste: her düğümde next ve prev vardır; geriye doğru gezilebilir, silmede önceki düğümü aramaya gerek kalmaz.
Sınav bağlantısı

Farz edin ki sorularında liste gezme kalıbı: d = liste.head; while (d != NULL) { …d = d->next; }. Hocanın kabul ettiği temel işlemler: head, next, FindNode/find, InsertNode, DeleteNode.
