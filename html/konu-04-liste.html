4.1Veri yapısı ve soyut veri tipi

Hocaya göre veri yapısı aslında bir depolama ünitesidir. Bir veri yapısı tanımlarken iki şey belirlenir:

  1. Nesneler kümesi: ne depolanacak? (int tam sayı, float ondalık, char karakter, öğrenci kaydı…)
  2. İşlemler kümesi: bu veriler üzerinde hangi işlemler yapılacak? int için toplama, çıkarma, çarpma, bölme. char için “a + b” toplama değil, yan yana koyma (“ab”) olabilir; “−” de iki kelimenin harf farkı olabilir.

Soyut veri tipi (SVT) = soyut veri yapısı (SVY): dildeki temel tipleri kullanarak kendi oluşturduğumuz, davranışını da kendimizin programladığı yeni tiptir. Dizi, string, char, byte gibi yapılar eskiden soyuttu; artık kütüphanede hazır geldikleri için temel veri yapısı sayılıyor.

Soyut veri yapısıyla soyut veri tipi aynı şey. Slaytların bir kısmında SVY, bir kısmında SVT geçer.

  • Soyutlama: x + y yazarken toplamanın nasıl yapıldığını düşünmeyiz; biri yazıp kütüphaneye koymuş. SVT de bunu sağlar.
  • class – struct farkı: class içinde değişkenler ve fonksiyonlar tanımlanabilir (fonksiyonu sadece sınıf içindekiler kullanır); struct'ta fonksiyonlar dışarıda tanımlanır ve başkası da kullanabilir (risk). Bu yüzden SVT C++'ta class ile tanımlanır; işlemler üye fonksiyon olur.
  • SVT örnekleri: küme (birleşim, kesişim, boyut, tersini alma), kuyruk (oluştur, ekle, incele, sil, yok et). Adları aynı olsa da iki SVY aynı değildir; arkadaki fonksiyonlar farklı olabilir.

4.3Dizi ile gerçekleştirme

Bağlantılı liste, dizinin şu dört dezavantajını ortadan kaldırmak için önerilmiştir:

  1. Sabit boyut: boyut derleme zamanında verilir; 10'luk diziye 11. eleman eklenemez (hata verir ya da eklenmez).
  2. Blok hafıza: 6'lık dizi için hafızada art arda 6 boş hücre gerekir; bir sürü 5'lik boşluk olsa da dizi oraya sığmaz video 8 Sıralama 5 28:05.
  3. Tek tip veri: dizi int ise her hücresi int'tir.
  4. Hücrede tek veri: öğrencinin no, ad ve soyadı için 3 ayrı dizi gerekir; “1. hücreler aynı öğrencinin” eşleşmesini yalnız programcı bilir.

Ekleme/silme: sona ekleme veya sondan silme sorunsuzdur. Başa ekleme yer açmak için tüm elemanları bir hücre aşağı kaydırır; baştan silme boş hücre kalmasın diye tüm elemanları yukarı kaydırır. Ortalamada listenin yarısı yer değiştirir.

4.4Bağlantılı listenin kavramsal yapısı

Elemanların hafızada art arda durması gerekmez: hafızanın neresine düşerse düşsün, her elemandan sonrakine bir bağlantı atılır. Hoca bunu tren ile anlatır:

  • head (baş, lider) = lokomotif: listenin başlangıcını gösterir, içinde veri yoktur (lokomotifte verinin olmaması gibi video 9 Liste 1 13:01).
  • Düğüm (node) = vagon: veri + sonraki düğümün adresi (işaretçi). 1. düğümde 2'nin adresi, 2'de 3'ün adresi vardır. Veri kısmında birden fazla ve farklı tipte veri olabilir (no, ad, soyad, okul…).
  • Son düğümün işaretçisi NULL'dır. Tahtada topraklama sembolü (veya boş küme işareti) ile çizilir: topraklama sembolü programlamada NULL'a denk gelir video 9 Liste 1 06:56. Aramada NULL'ı görünce durulur; 3 elemanlı listeye insert(5, x) denirse NULL görülür ve kullanıcıya hata verilir.
  • Diziden farkı: dizide işaretçi yoktur, başlangıcı bilmek yeter (int 4 byte ise ilk 4 byte 1. hücredir).
  • Dezavantajı, işaretçi için ek yer video 9 Liste 1 10:40: veri 1 MB, işaretçi 16 KB ise ihmal edilir; ama veri küçükse işaretçiler çok yer kaplar ve tek avantaj veriyi dağınık tutabilmek kalır.
  • Bağlantı koparsa video 9 Liste 1 12:09: vagonlar arasındaki bağlantıyı kaybetmek gibi, bağlantılı listenin arasındaki verileri de kaybederiz; hafızada hiçbir yere bağlı olmayan serseri veri kalır.

4.6Bağlantılı liste gerçekleştirmesi (C++)

Önce kavramsal yapı kâğıt kalemle tasarlanır, sonra iki sınıfla programlanır: Node düğümü, List listeyi ve işlemlerini tanımlar.

class Node {
public:
    double data;      // veri (ogrenci icin no, ad, soyad olabilir)
    Node*  next;      // sonraki dugume isaretci
};
class List {
public:
    List(void) { head = NULL; }             // yapici: bos liste
    ~List(void);                            // yikici
    bool  IsEmpty() { return head == NULL; }
    Node* InsertNode(int index, double x);
    int   FindNode(double x);
    int   DeleteNode(double x);
    void  DisplayList(void);
private:
    Node* head;       // ilk dugumu gosterir; verisi yok (lokomotif)
};
  • data: anlatım basit olsun diye tek bir double. İstenirse int ogrNo;, string ad;, string soyad;, int bolumKodu; gibi alanlarla genişletilir.
  • next: sonraki eleman da bir Node olduğu için işaretçi kendi cinsinden bir adresi tutar: Node*.
  • public / private video 9 Liste 1 19:05: public her yerden erişilir (Node'un data ve next'ine dışarıdan yazılabilir); private'a yalnız sınıfın kendi fonksiyonları erişir. protected ders kapsamında değil. head private'tır: listenin başlangıcını dışarıdan kimse değiştirememeli. head de bir Node*'dır ama verisi yoktur.
  • Yapıcı (constructor) video 9 Liste 1 23:19: sınıfla aynı isimde, girdisi void; değişken tanımlandığı anda otomatik çalışır. Hoca: int x; satırını gören derleyici hafızada yer ayırıp “x burası” der; List ogrenciListesi; satırını görünce de yapıcı çalışır, head'i oluşturur, NULL atar ve bekler. InsertNode – belirtilen konumdan sonra ekleme

Mantık: index'inci düğüm bulunur, oradaki bağlantı koparılıp araya “kaynak yapılır”. Hoca bunu dört adımda anlatır video 9 Liste 1 36:38 (önceki düğüm A, sonraki B, yeni düğüm Y):

  1. index'inci elemanı bul; bulunamazsa hata ver ve çık.
  2. Yeni düğüm için yer aç (new Node) ve x'i içine kopyala (hafıza doluysa düğüm oluşturulamaz).
  3. Yeni düğüm sonrakini göstersin: A'nın next'indeki B adresi Y'nin next'ine kopyalanır.
  4. Önceki düğüm yeni düğümü göstersin: Y'nin adresi A'nın next'ine yazılır.

Dört durum, kodda iki grup: (1) boş listeye ekleme, (2) en öne ekleme ⇒ ikisi de head'den hemen sonra (index == 0); (3) sona ekleme (yeni düğüm artık NULL'ı gösterir), (4) ortaya ekleme ⇒ else kolu.

Hoca derste vurguladı video 9 Liste 1 42:11

Head değişmiyor arkadaşlar. Dikkat edin. Head hiçbir zaman değişmeyecek. Lokomotif aynı kalır, vagonlar değişir. head değişkeni yapıcıda bir kez oluşturulur; başa eklemede değişen şey yalnız head'in tuttuğu adrestir (head = newNode). Veriye ihtiyaç olunca head'in gösterdiği düğümden başlanır.

Node* List::InsertNode(int index, double x) {
    if (index < 0) return NULL;                       // 1. hata kontrolu
    int currIndex = 1;
    Node* currNode = head;
    while (currNode && index > currIndex) {           // ADIM 1: bul
        currNode = currNode->next;
        currIndex++;
    }
    if (index > 0 && currNode == NULL) return NULL;   // 2. hata kontrolu
    Node* newNode = new Node;                         // ADIM 2
    newNode->data = x;
    if (index == 0) {                                 // head'den hemen sonra
        newNode->next = head;                         // ADIM 3
        head = newNode;                               // ADIM 4
    } else {                                          // ortaya / sona
        newNode->next = currNode->next;               // ADIM 3
        currNode->next = newNode;                     // ADIM 4
    }
    return newNode;
}
  • List:: fonksiyonun List sınıfına ait olduğunu söyler (sınıf dışında yazıldığı için).
  • 1. hata kontrolü: head 0. eleman olduğu için negatif indeksten sonra ekleme olamaz; NULL “eklenemedi” demektir.
  • currIndex = 1, currNode = head: “şu an 1 numaralı düğümdeyim”.
  • while'da iki kriter && ile bağlıdır, ikisi de doğru olmalı: currNode NULL değil (liste bitmedi) ve index > currIndex (aranan yere gelinmedi). Gövde bir sonraki düğüme zıplar ve indeksi artırır.
  • 2. hata kontrolü: index >0 olduğu hâlde currNode NULL olduysa öyle bir konum yoktur (ör. 4 düğümlü listeye InsertNode(10, 25)).
  • index == 0 kolunda head'in eski bağlantısı üzerine yazıldığı için kendiliğinden kopar.
  • İşaretçi nedir? Hoca video 9 Liste 1 60:15: Bizim bir evimiz var, evin adresi var; her yere evi taşımaya gerek yok, o adrese posta gelir.
Bağlantı sırası

FindNode – arama

Hoca: InsertNode'daki while'ı modifiye ediyoruz; ikinci kriter currNode->data != x olur.

int List::FindNode(double x) {
    Node* currNode = head;
    int currIndex = 1;
    while (currNode && currNode->data != x) {
        currNode = currNode->next;
        currIndex++;
    }
    if (currNode) return currIndex;            // bulundu: konumu
    return 0;                                  // bulunamadi
}

DeleteNode – silme

InsertNode ile hemen hemen aynı mantık: (1) silinecek düğümü bul, (2) düğümü sil, (3) silinen düğümün öncesini ve sonrasını bağla (trenden vagon çıkarmak). İki durum vardır: ilk düğümü (head'den hemen sonrakini) silmek ve ortadan/sondan silmek. Önceki düğümün next'i değişeceği için prevNode (previous node) tutulur; FindNode'a göre while'a eklenen tek satır budur.

int List::DeleteNode(double x) {
    Node* prevNode = NULL;
    Node* currNode = head;
    int currIndex = 1;
    while (currNode && currNode->data != x) {
        prevNode = currNode;                   // oncekini kaybetme
        currNode = currNode->next;
        currIndex++;
    }
    if (currNode) {                            // bulundu
        if (prevNode) {                        // ortadan / sondan sil
            prevNode->next = currNode->next;
            delete currNode;
        } else {                               // ilk dugumu sil
            head = currNode->next;
            delete currNode;
        }
        return currIndex;
    }
    return 0;                                  // bulunamadi
}

DisplayList ve yıkıcı

void List::DisplayList() {
    int num = 0;                               // kac dugum yazildi (istege bagli)
    Node* currNode = head;
    while (currNode != NULL) {
        cout << currNode->data << endl;        // printf de olurdu
        currNode = currNode->next;
        num++;
    }
    cout << "Number of nodes in the list: " << num << endl;
}
List::~List(void) {
    Node* currNode = head, *nextNode = NULL;
    while (currNode != NULL) {
        nextNode = currNode->next;             // listenin ucunu tut
        delete currNode;
        currNode = nextNode;
    }
}

DisplayList (D1 → D2 → D3): CN = A1 → D1 yazılır, num = 1; A2 → D2, num = 2; A3 → D3, num = 3; CN = NULL olunca döngüden çıkılır ve düğüm sayısı yazılır. endl yüzünden veriler alt alta çıkar.

Yıkıcı 3 düğümde: CN = A1, NN = A2, A1 silinir, CN = A2; NN = A3, A2 silinir, CN = A3; NN = NULL, A3 silinir, CN = NULL ⇒ bütün liste baştan sona silinmiştir.
